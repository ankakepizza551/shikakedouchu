# 仕掛け道中

罠を仕込みながら進む、読み合いすごろく。ブラウザで遊べる2〜4人用のオンライン対戦ゲームです。

**遊ぶ → https://sugoroku-online-satin-wildflower-6921.fly.dev/**

インストールもアカウント登録も不要です。ルームを作って、コードか招待リンクを友達に送るだけで始められます。

![仕掛け道中](client/og.png)

## 遊び方

ゴールに先に着いた人の勝ちです。毎ラウンド、次の2つを繰り返します。

1. **配置フェーズ**：手札3枚から仕掛けを1枚選び、スタートとゴール以外の好きなマスに置きます。誰がどこに何を置いたかは、置いた本人にしか分かりません。
2. **行動フェーズ**：順番にサイコロを振って進みます。仕掛けのあるマスに止まると発動します。自分が置いた仕掛けも踏みます。

道は途中で3本に分かれます。どれを通るかは、いつでも切り替えられます。

| 街道 | 特徴 |
| --- | --- |
| 🌸 桜街道 | 遠回り |
| 🎋 竹林街道 | 標準 |
| 🌊 藤街道 | 近道 |

ラウンド上限に達したら、その時点でゴールに近い順に順位が決まります。

### 仕掛け

| 仕掛け | 効果 |
| --- | --- |
| 🕳️ 落とし穴 | 4マス戻る |
| 🚧 関所 | 次のターンお休み |
| 🌪️ 辻風 | 次のサイコロの出目が1になる |
| 👥 影武者 | 設置者と位置を交換する |
| 🧲 引導石 | 最も近い他プレイヤーのマスへ引き寄せられる |
| 🌊 急流 | 3マス進む |
| 🏚️ 大崩れ | 他の全員が2マス戻る |
| 📣 呼び子 | 射程内の全員が設置者のマスへ集まる |
| 🎆 大筒花火 | 踏んだ人が4マス、同じマスと隣のマスにいる人が2マス戻る |
| ❓ 千両箱 | 上のどれかがランダムに発動する |

仕掛けで動いた先にも仕掛けがあれば、最大3回まで連鎖します。

### そのほか

- 60秒操作がないとキックされます。
- 接続が切れても、90秒以内なら元の席に戻れます（ページを読み込み直しても戻れます）。
- マス数は15・20・30、ラウンド上限は10・20・30・50から選べます。
- 非公開ルームにすると、公開ルーム一覧に表示されません。

## 自分の環境で動かす

Node.js 18 以上が必要です。

```sh
npm install
npm start
```

http://localhost:3000 を開きます。複数のタブで開けば1人でも動作を確認できます。

```sh
npm test
```

ゲームのルールと、サーバーとの通信をテストします。

### 手元のサーバーを友達に公開する

Windows なら `start-public.ps1` で、サーバーの起動と外部公開をまとめて行えます。[cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/) が必要です。

```powershell
.\start-public.ps1
```

表示された `trycloudflare.com` のURLを共有してください。

## 構成

```
client/
  index.html       画面
  game.js          描画・演出・サーバーとの通信
  boardLayouts.js  盤面の定義（サーバーと共用）
  style.css
server/
  index.js         Socket.IO のハンドラ、再接続、キックタイマー
  gameLogic.js     ルーム管理とゲームのルール
test/
```

サーバーは Express と Socket.IO で、クライアントはフレームワークなしの JavaScript です。

ルームの状態はサーバーのメモリ内だけにあります。サーバーを再起動すると進行中のゲームは消えます。また、複数台に分けて動かすとルームが台ごとに分かれてしまうので、1台で動かしてください。

本番は [Fly.io](https://fly.io/) で動かしています。

```sh
fly deploy --ha=false
```
